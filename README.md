프로젝트 개요
중고 도서 및 굿즈 거래를 지원하는 웹 기반 전자상거래 서비스입니다.
회원 기능, 장바구니, 주문·결제, 리뷰 기능을 포함한 전체 구매 흐름을 구현했습니다.

주요 기능
- 회원 가입 및 로그인 기능
- 도서·굿즈 목록 조회 및 상세 보기
- 장바구니 및 주문 처리
- 카카오페이 외부 API 연동 결제 기능
- 주문 내역 조회 및 리뷰 작성

담당 역할
- Spring MVC 기반 백엔드 로직 구현
- MyBatis를 활용한 Oracle Database 연동
- 주문·결제 관련 기능 구현
- 전체 테이블 설계 및 데이터 정합성 관리
- 카카오페이 API 연동을 통한 결제 처리 구현

기술 스택
Spring MVC / MyBatis / Oracle Database / JSP / HTML / CSS / JavaScript / jQuery / Tomcat / Kakao Pay API

개발 목적 및 배운 점
금융 데이터가 실제 결제로 이어지는 흐름을 구현하며,
데이터 정합성과 예외 처리가 서비스 신뢰에 직결된다는 점을 경험했습니다.
